# Model v2: walk-forward evaluation

Every graded game from 2026-10-20 with box scores and a projection run logged before tip. `season` is what was logged live; `rolling` is recomputed as of each tip with the same scenarios, from earlier dates' box scores only; `books` is the closing consensus mean. Errors are projection minus actual. Points, rebounds and assists are scored on the player-games all three cover where the player played (a prop voids otherwise); minutes on every player a source projected, a player who sat counting 0. Only the out-of-sample window counts toward promotion (docs/MODEL_V2_PLAN.md). Generated by `python -m cold_start_usage.cli evaluate --docs`.
