## How it is measured

- **Offseason effect, not method noise.** Every team is run twice through the same automatic rotation: once on its 2026-27 roster, once with this summer's moves undone. The difference is the offseason's effect on each player's usage, so the rotation method's own bias cancels out.
- **Situations.** *arrival*: new team. *vacuum*: incumbent on a team that lost usage (team effect <= -2%) whose own usage rises by >= 0.5 points. *squeeze*: the reverse. *steady*: everything else.
- **Where players are.** Manual overrides, then the NBA.com offseason tracker, then SportsGameOdds rosters, then last season's team (36 players assumed). Only listed offseason moves count as arrivals or departures, so trade-deadline moves don't.
- **Projections** use reviewed minutes where they exist (MIA, TOR) and the automatic rotation elsewhere, which assumes everyone is healthy and ignores rookies.
- **Model property.** The elasticity spreads a team's usage change almost evenly in *points*, so low-usage players get the biggest *relative* change. That is where the model has the most to say.
